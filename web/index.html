Install LanyardBadge

For the 4 MB CYD2USB with an ST7789 display and USB connectors at the bottom.

Updates write only the application. Cards and settings stay in place. The existing layout must have a 2 MiB app at 0x10000 and storage at 0x210000. Other layouts need a flash backup and manual migration.

Use a desktop browser with Web Serial and a USB data cable. Close other serial tools first.

USB installation is supported. Wireless firmware updates are unavailable.
